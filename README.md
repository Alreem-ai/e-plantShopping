# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with **React** and **Redux Toolkit**. It lets customers browse a catalog of houseplants and manage a shopping cart.

### Features
- **Landing page** with the company name, an About Us section, a background image and a *Get Started* button.
- **Product listing** grouped into categories (Air Purifying, Aromatic, Insect Repellent, Medicinal, Low Maintenance), each plant showing its image, name, description and price with an *Add to Cart* button that disables once the plant is added.
- **Navigation bar** with links to Home, Plants and the Cart, plus a cart icon that shows the live item count.
- **Shopping cart** showing each plant's thumbnail, unit price, quantity controls (+ / −), subtotal and a Delete button, along with the total cart amount, *Continue Shopping* and *Checkout* (coming soon).

### Tech stack
React 18 · Redux Toolkit · React Redux · Vite · GitHub Pages
